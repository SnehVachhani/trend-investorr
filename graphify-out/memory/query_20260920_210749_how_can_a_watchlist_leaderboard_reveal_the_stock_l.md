# Q: How can a watchlist leaderboard reveal the stock-level evidence behind one filter combination?

## Answer

Each overall leaderboard row now includes a View stocks action. Its modal lists every analyzed stock for that filter, preserving watchlist order and showing the stock name, market behaviour, one-year move, trend efficiency, filter return, drawdown, trade count, and completion status.
